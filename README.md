# AirTag Retro Computer Project

This repository contains five hardware and firmware architectures for building a wireless-keyboard retro computer or game console inside an **Apple AirTag case** ($31.9\text{ mm}$ diameter $\times 8.0\text{ mm}$ thick).

**Review (2026-11-07):** every directory now has a `REVIEW.md` listing what the first drafts got wrong and what was verified. Shared code lives in [`common/`](file:///home/ccd/retro_pc_project/common) (`hstx_dvi.c`: RP2350 HSTX DVI 640x480 scanline driver used by projects 2, 3 and 5; `font8x8_basic.h`, public domain). Cross tools (ARM GCC, QEMU, Pico SDK, scripts) are in [`tools/`](file:///home/ccd/retro_pc_project/tools); `tools/install_arduino_cli.sh` installs the ESP32 compiler and `tools/compile_sketch.sh <beetle variant> <sketch>` builds a sketch; all three Beetle sketches compile for the ESP32-C6 and ESP32-C3 (Huge APP partition scheme). The Beetle that fits the case is the ESP32-C6 or ESP32-C3 (25 x 20.5 mm, 4 MB flash; 512 or 400 KB SRAM); the classic Beetle ESP32 is 35 x 34 mm. The Beetle's 32.3 mm diagonal exceeds the AirTag's 31.9 mm outer diameter, so the case fit is the first thing to measure.

## Project Sections

### 1. [`01_ti994a_emulator/`](file:///home/ccd/retro_pc_project/01_ti994a_emulator) — Dual-Board TI-99/4A Console Emulator (`Option A`)
Stacks your friend's **Beetle ESP32** with a **$4 Waveshare RP2350-Zero** inside the AirTag case to run a full **Texas Instruments TI-99/4A** emulator (`PicoPlus-devel/pico-994A`) with **640×480 @ 60Hz HDMI Video + Digital HDMI Audio**.
* **[01_ti994a_emulator/PLAN.md](file:///home/ccd/retro_pc_project/01_ti994a_emulator/PLAN.md)** — Geometry fit table, BOM, pin-by-pin wiring map, PSRAM notes, and TI-99/4A `FCTN` keyboard cheat sheet.
* **[beetle_ble_bridge.ino](file:///home/ccd/retro_pc_project/01_ti994a_emulator/beetle_firmware/beetle_ble_bridge.ino)** — Beetle ESP32-C6/C3 firmware (NimBLE-Arduino 2.x) that pairs with BLE keyboards, streams 13-byte HID frames over UART1 to `pico-994A`, outputs PS/2 Set 2 for PS/2 emulators, and hosts a Wi-Fi **TI-99/4A function pad** (key codes fixed in the review).
* **[uart_hid_bridge.cpp](file:///home/ccd/retro_pc_project/01_ti994a_emulator/rp2350_pico994a/uart_hid_bridge.cpp)**, **[pico994a_uart_hid.patch](file:///home/ccd/retro_pc_project/01_ti994a_emulator/rp2350_pico994a/pico994a_uart_hid.patch)** & **[build_pico994a.sh](file:///home/ccd/retro_pc_project/01_ti994a_emulator/rp2350_pico994a/build_pico994a.sh)** — UART1 receiver that fills pico-994A's shared keyboard/gamepad state (the function the first draft called does not exist), the two-line patch that hooks it in, and the build script (HW_CONFIG 2 with HSTX; verified: pico-994A builds to a UF2 with the bridge).

### 2. [`02_beetle_terminal_os/`](file:///home/ccd/retro_pc_project/02_beetle_terminal_os) — Standalone Beetle VT100 Terminal, Minimal OS & SSH-2 Client
Uses **only the Beetle board** (plus a passive resistor video output or optional dumb HDMI display card) to create a self-contained **80×25 VT100/ANSI terminal** with wireless Bluetooth keyboard input, local flash storage, Telnet, and **encrypted SSH-2 (`LibSSH-ESP32`)**:
* **[02_beetle_terminal_os/PLAN.md](file:///home/ccd/retro_pc_project/02_beetle_terminal_os/PLAN.md)** — Memory budget, wiring diagrams for all 3 video options, and architectural guide for both OS options.
* **Three Selectable Video Backends ([`video_backends/`](file:///home/ccd/retro_pc_project/02_beetle_terminal_os/video_backends)):**
  1. **[video_composite_spi.h](file:///home/ccd/retro_pc_project/02_beetle_terminal_os/video_backends/video_composite_spi.h)** — 2-resistor composite: **non-working stub** (the first draft's timer-interrupt SPI design cannot run beside BLE/Wi-Fi on a single-core C3/C6); keeps the VT100 model and a real font.
  2. **[video_vga_fabgl.h](file:///home/ccd/retro_pc_project/02_beetle_terminal_os/video_backends/video_vga_fabgl.h)** — FabGL VGA, classic dual-core ESP32 only (a 35 x 34 mm board, not for the AirTag).
  3. **[video_uart_rp2350_hdmi.h](file:///home/ccd/retro_pc_project/02_beetle_terminal_os/video_backends/video_uart_rp2350_hdmi.h)** & **[rp2350_hdmi_vt100_card.c](file:///home/ccd/retro_pc_project/02_beetle_terminal_os/video_backends/rp2350_hdmi_vt100_card.c)** — the recommended path: the RP2350-Zero as a **921600-baud UART to Micro-HDMI 80×30 colour ANSI display card**, now a complete HSTX implementation that builds with the Pico SDK (UF2; not yet run on hardware).
* **Two Operating System Options:**
  * **OS Option A — FreeRTOS Unix-Like Micro-Shell ([`beetle_rtos_ssh_terminal.ino`](file:///home/ccd/retro_pc_project/02_beetle_terminal_os/os_freertos_shell/beetle_rtos_ssh_terminal.ino)):** Boots to an `airtag:~$` shell on the 2 MB LittleFS flash with built-in `ssh user@host`, `telnet`, `wifi scan/join`, `ls`, `cat`, `rm`, and `ed` text editor.
  * **OS Option B — Vintage 192K CP/M 2.2 with RAM Disk, Bank Switching & `SSH.COM` ([`beetle_cpm22_ssh.ino`](file:///home/ccd/retro_pc_project/02_beetle_terminal_os/os_cpm22_runcpm/beetle_cpm22_ssh.ino) & [`ssh_com_bdos_ext.h`](file:///home/ccd/retro_pc_project/02_beetle_terminal_os/os_cpm22_runcpm/ssh_com_bdos_ext.h)):** Boots a Z80 CP/M 2.2 environment with a **63.5 KB contiguous TPA**, a **128 KB Silicon RAM Disk (`Drive B:` / `M:`)** in SRAM for zero-latency `.OVR` overlays & compiler scratch files, an **8-bank (128 KB) MMU paging window at `0x8000–0xBFFF`** (`OUT (0F0h), A` / `BANK.COM`), and real Z80 transient binaries (`SSH.COM`, `TELNET.COM`, `WIFI.COM`, `BANK.COM` via [`make_cpm_tools.py`](file:///home/ccd/retro_pc_project/02_beetle_terminal_os/os_cpm22_runcpm/make_cpm_tools.py)) that trap into the ESP32's hardware-accelerated `LibSSH-ESP32` stack (`BDOS 220–223`).

### 3. [`03_rp2350_standalone_emulators/`](file:///home/ccd/retro_pc_project/03_rp2350_standalone_emulators) — RP2350-Zero Primary Multi-System Emulators (Standalone or w/ Beetle Wireless Co-Processor)
Uses the **$4 Waveshare RP2350-Zero** as the primary dual-core emulator (`Core 0` = Vintage CPU; `Core 1` = Scanline Beam-Racing Video/Sprite Coprocessor + Audio DSP + Hardware HSTX HDMI), with the option to keep the **Beetle ESP32** inside the case for Bluetooth keyboard + Wi-Fi disk/modem support (eliminating any external USB OTG host+power splitter):
* **[03_rp2350_standalone_emulators/PLAN.md](file:///home/ccd/retro_pc_project/03_rp2350_standalone_emulators/PLAN.md)** — Deep-dive comparison of **Apple //e, Apple //c, IBM PCjr, IBM PC XT, Commodore 64, and TI-99/4A** on a bare 520 KB SRAM RP2350-Zero vs. with the optional $1.50 8 MB PSRAM chip.
* **[rp2350_hstx_beamracer.h](file:///home/ccd/retro_pc_project/03_rp2350_standalone_emulators/dual_core_engine/rp2350_hstx_beamracer.h)** & **[standalone_emulator_main.c](file:///home/ccd/retro_pc_project/03_rp2350_standalone_emulators/dual_core_engine/standalone_emulator_main.c)** — Core 1 scanline renderers (Apple II hi-res / double hi-res, PCjr 16-colour, C64 text mode + 8 sprites with collisions, TMS9918A Graphics I/II + sprites) now driving real HSTX DVI output through `common/hstx_dvi.c`; builds for all four machines (UF2). Core 0 is a stub: **no CPU emulation yet**, and the plan lists each renderer's gaps.
* **[build_all_rp2350_emulators.sh](file:///home/ccd/retro_pc_project/03_rp2350_standalone_emulators/build_all_rp2350_emulators.sh)** — Fetches and configures existing open-source RP2350 emulators (`frank-apple`, `AppleIIcEmulatorPicoSeries`, `pico-286`, `frank-c64`, `pico-994A`).

### 4. [`04_game_consoles_and_amiga/`](file:///home/ccd/retro_pc_project/04_game_consoles_and_amiga) — Game Consoles (ColecoVision, Atari 5200, Atari 7800, 16-Bit) & Amiga / 68000 Systems
Explores how 8-bit and 16-bit consoles plus Motorola 68000 computers map onto the AirTag hardware:
* **[04_game_consoles_and_amiga/PLAN.md](file:///home/ccd/retro_pc_project/04_game_consoles_and_amiga/PLAN.md)** — Why 8-bit consoles (**ColecoVision, Atari 5200, Atari 7800, NES, Master System**) are actually *easier* than home computers on the RP2350-Zero (`1 KB–16 KB` system RAM + scanline line-buffers), how **Macintosh 128K/512K (`umac`)** and **Atari ST** run on the RP2350, and how to put a cycle-exact **Amiga 500/1200 (`NanoMig`)** inside the AirTag using the **$22.9 \times 17.8\text{ mm}$ Sipeed Tang Primer 25K FPGA SoM** + Beetle/RP2350 companion.
* **[console_scanline_engines.h](file:///home/ccd/retro_pc_project/04_game_consoles_and_amiga/console_scanline_engines.h)** — Core 1 scanline renderers for the **Atari 7800 `MARIA`** display list (160A direct and indirect modes), **Atari 5200 `GTIA`** players and missiles with sizes, the **ColecoVision** keypad encoding, and the **Macintosh `512×342`** 1-bit screen; what each one still lacks is stated in the header.
* **[build_consoles_and_68k.sh](file:///home/ccd/retro_pc_project/04_game_consoles_and_amiga/build_consoles_and_68k.sh)** — Fetches and sets up `Pico2Atari8` (Atari 5200/800), `pico-smsplus` (SMS/Coleco), `pico-infonesPlus` (NES), `pico-genesisPlus` (Genesis), `pico-snesPlus` (SNES), `pico-mac` (`umac`), and `NanoMig` (Amiga FPGA).

### 5. [`05_accessible_speech_retro_pc/`](file:///home/ccd/retro_pc_project/05_accessible_speech_retro_pc) — Accessible "Talking" Retro Computer (RP2350 Core 1 DECtalk / ESPK + Hypervisor Screen Reader)
Dedicates the RP2350-Zero's second core to a software speech synthesizer that the emulated machine sees as a serial **RC Systems DoubleTalk LT**, plus an **out-of-band hypervisor screen reader** that reads the emulated video RAM, so CP/M, DOS (with unmodified GPL `PROVOX7.EXE`) and every unpatched Apple //e disk talk with **zero emulated RAM or CPU cost**. Engines come from [`/home/ccd/vintage-pc-speech`](file:///home/ccd/vintage-pc-speech/README.md) / [`/home/ccd/accessible_os/freedos`](file:///home/ccd/accessible_os/freedos/src/dectalk/NOTES.md): **DECtalk 4.x ARM7** (12.4 % Whisper WER, 667 KB flash, 54 KB SRAM, 3.5 % of a 150 MHz core) and **ESPK** (eSpeak-NG + integer Klatt, GPLv3, 514 KB, 1.8 %). The screen reader follows [`/home/ccd/rust-tdsr`](file:///home/ccd/rust-tdsr/CLAUDE.md) (review cursor, key-echo detection, highlight tracking).
* **[05_accessible_speech_retro_pc/PLAN.md](file:///home/ccd/retro_pc_project/05_accessible_speech_retro_pc/PLAN.md)** — architecture, measured engine costs and memory budget, the three personalities (Talking CP/M 2.2, PC XT with Provox 7 on a virtual DoubleTalk at `COM2`, Apple //e universal Textalker), verification matrix and open items. **[REVIEW.md](file:///home/ccd/retro_pc_project/05_accessible_speech_retro_pc/REVIEW.md)** — the 27 defects found in the first draft and how they were fixed and measured.
* **[speech_core1/](file:///home/ccd/retro_pc_project/05_accessible_speech_retro_pc/speech_core1)** — `doubletalk_core1.[ch]` (Core 0/Core 1 FIFOs, race-free `^X` flush protocol, DoubleTalk parser from `dtalkd`, 16550 register view, PCM ring for both audio outputs), `engine_dectalk.c` (the non-NULL callback fix, full dictionary, `CHEESY_DICT_COMPRESSION`), `engine_espk.c` + `espk_data_mem.c` (`ESPK.DAT` served from flash in place).
* **[screen_reader/tdsr_hypervisor_reader.[ch]](file:///home/ccd/retro_pc_project/05_accessible_speech_retro_pc/screen_reader/tdsr_hypervisor_reader.c)** — VRAM adapters for the 80×30 VT100 cell grid, Apple //e `$0400` (40/80 column, flashing, MouseText, `ALTCHARSET`) and CGA `B8000`; scroll compensation, key-echo suppression, console vs repaint rules, highlight tracking, rust-tdsr review keys.
* **Verification:** [`host_test/`](file:///home/ccd/retro_pc_project/05_accessible_speech_retro_pc/host_test) runs the Core 1 code with the real engines (105 checks, WAVs transcribed with Whisper); [`arm_qemu/`](file:///home/ccd/retro_pc_project/05_accessible_speech_retro_pc/arm_qemu) runs the same code on QEMU's Cortex-M33 with instruction counting (output byte-identical to the host); [`pico_firmware/`](file:///home/ccd/retro_pc_project/05_accessible_speech_retro_pc/pico_firmware) is a Pico SDK project for the RP2350-Zero (PWM headphone audio on GPIO 20/21, 64 KB Core 1 stack) that builds to `talking_retro.uf2`; [`cpm_disk_A/speak.asm`](file:///home/ccd/retro_pc_project/05_accessible_speech_retro_pc/cpm_disk_A/speak.asm) → `SPEAK.COM` (`A>SPEAK [/Sn] [/Pnn] [/Vn] [/On] [/X] text`, BDOS 224) tested under z80pack `cpmsim`. [`build_accessible_retro.sh`](file:///home/ccd/retro_pc_project/05_accessible_speech_retro_pc/build_accessible_retro.sh) `[--arm] [--pico] [--cpm] [--whisper]` drives all of it. Not yet done: HDMI data-island audio, real hardware.
